Checks a Unity macOS game for the iPad loader: Unity version, IL2CPP vs Mono, whether GameAssembly.dylib has an arm64 slice, what it links, and native plugins. Files are read on this phone and never uploaded.

    Send the report to the build repo

    The report holds names and versions only (no game code or assets). The iPadOS symbol check on GitHub reads it.

    1. Tap Copy report.
    2. In the repo on github.com: Add file → Create new file, name it reports/<game>.json, paste, commit.
    3. Open the Actions tab: the ios-symbol-check run lists any symbol the iPad lacks.
